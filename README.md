# マインクラフト疑似サーバーシステム

## 概要
オンラインストレージとPCを使ってサーバーっぽいことをする

### サーバーっぽいこととは？
- みんなでプレイできる(最優先事項)
  - だれでも自由に遊べる(起動できる)
- バックアップが比較的簡単に取れる
  - 一定時間ごとにとれる
  - やりたくなったらすぐとれる
- MODとかいれやすい(らしい)

### しかし

サーバーを立てるのはめんどくさい
- お金がかかる
- 手間もかかる
- ややこしい
- そもそもよくわからん
ので、よくわかっている仕組みを利用することに

### 具体的には？
- 実際にゲームを動かすのはパソコンで
- 外部ストレージにデータを保管して、遊ぶときにダウンロードする
- このアップロード～プレイ～ダウンロードまでの仕組みをワンボタンでできるようにする
